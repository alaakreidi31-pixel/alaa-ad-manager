# ADR 0003: PostgreSQL مثبّت مباشرة على Windows بدلاً من Docker

- **الحالة:** منفّذ
- **التاريخ:** 2026-11-13
- **يعدّل:** الخطة الأصلية التي اقترحت تشغيل PostgreSQL عبر Docker. التعديل تم بموافقة صاحبة المشروع.

## السياق

الخطة الأولى اقترحت Docker Desktop لتشغيل PostgreSQL محلياً. أثناء تجهيز البيئة ظهر من مدير المهام (Task Manager) أن جهاز التطوير:

- معالج بنواتين (2 cores).
- ذاكرة 7.5 GB، مستخدم منها 71% قبل بدء العمل.

Docker Desktop على Windows يحتاج WSL2، ويستهلك عدة جيجابايت من الذاكرة وحده.

كما تبيّن أن **PostgreSQL 17 مثبّت مسبقاً** على الجهاز لمشروع آخر.

## القرار

- استخدام PostgreSQL 17 المثبّت مباشرة على Windows، وعدم تثبيت Docker أو WSL2.
- مستخدم خاص بالمشروع `alaa_app`، بصلاحية `LOGIN` و`CREATEDB` فقط، وليس مستخدم المدير `postgres`.
- قاعدتان يملكهما `alaa_app`: `alaa_ad_manager_dev` و`alaa_ad_manager_test`، بترميز UTF8.
- قواعد المشروع الآخر على نفس الخادم لم تُلمس.

## ما تم التحقق منه

| البند              | الدليل                                                              |
| ------------------ | ------------------------------------------------------------------- |
| مكان التثبيت       | المجلد `C:\Program Files\PostgreSQL\17` موجود                       |
| النسخة             | 17.11، من نتيجة `SELECT version();`                                 |
| الخدمة             | ظهرت بحالة `Running` في `Get-Service postgresql*` بتاريخ 2026-11-13 |
| عدم استخدام Docker | لا يوجد في المشروع `docker-compose.yml` ولا `Dockerfile`            |
| رابط الاتصال       | `localhost:5432` في `apps/api/.env.example`                         |
| الترميز والمالك    | `UTF8` و`alaa_app`، من نتيجة الأمر `\l`                             |

## البدائل التي لم تُختر

- **Docker Desktop:** ثقيل على مواصفات الجهاز الحالي.
- **قاعدة بيانات سحابية مجانية:** تحتاج اتصالاً دائماً بالإنترنت، وتجعل التطوير أبطأ.

## النتائج

- لا تكلفة إضافية على ذاكرة الجهاز.
- **إعداد الترتيب (collation) للقاعدتين هو `Arabic_Saudi Arabia.1256`**، لأنه مأخوذ من إعدادات Windows. خادم الإنتاج سيكون على الأرجح بإعداد مختلف، لذلك يجب ألا تعتمد أي ميزة أو اختبار على ترتيب قاعدة البيانات الافتراضي، بل على ترتيب صريح في الاستعلام.
- البيئة المحلية تختلف عن بيئة الإنتاج المستقبلية، وهذا مقبول في هذه المرحلة.

## متى نراجعه

- عند تجهيز النشر: Docker مخطط لاستخدامه في GitHub Actions وعلى خادم النشر، وليس على جهاز التطوير. هذا **لم يُنفَّذ بعد**.
- إذا تغيّر جهاز التطوير إلى جهاز بمواصفات أعلى.
