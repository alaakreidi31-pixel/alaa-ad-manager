# ADR 0015: الجلسة في الواجهة، والتنقل بـ React Router 7

- **الحالة:** منفّذ في الخطوة 1.7
- **التاريخ:** 2026-11-15
- **وافقت عليه:** صاحبة المشروع (خطة الخطوة 1.7)

## السياق

الخطوة 1.7 أضافت صفحة الدخول إلى الواجهة. يجب أن نقرر أين يُحفظ الـ Access Token في المتصفح، وكيف يُجدَّد، وكيف ننتقل بين الصفحات.

## القرار

**1. الـ Access Token في الذاكرة فقط**

- يُحفظ في متغير داخل React (`useRef`)، **وليس في `localStorage` ولا `sessionStorage`**. أي كود خبيث في الصفحة (XSS) لا يجده في تخزين المتصفح.
- عند تحديث الصفحة يضيع من الذاكرة، فتُستعاد الجلسة تلقائياً بطلب `POST /api/auth/refresh`، الذي يستخدم الـ cookie المحمي (`httpOnly`).

**2. التجديد التلقائي**

- يُجدَّد الـ Access Token قبل انتهائه بدقيقة (يعيش 15 دقيقة)، فلا ينقطع العمل.
- **طلب تجديد واحد فقط في كل لحظة.** كل refresh token يعمل مرة واحدة (ADR 0011). لو أُرسل طلبا تجديد معاً بالـ cookie نفسه، لاعتبر الخادم الثاني رمزاً مسروقاً وأغلق كل الجلسات. لذلك الطلبات المتزامنة تتشارك نتيجة طلب واحد (`refreshSession` في `apps/web/src/lib/auth-api.ts`). هذا مهم خصوصاً لأن React في وضع التطوير (`StrictMode`) يشغّل كل `useEffect` مرتين.

**3. رسائل الخطأ بالرموز**

- الخادم يعيد مع كل خطأ دخول حقلاً `code` ثابتاً (مثل `invalid_credentials` و`account_locked`)، والواجهة تترجمه إلى العربية أو الإنجليزية. الكود في `apps/api/src/auth/auth.http-errors.ts`.

**4. React Router 7، وليس 8**

- المكتبة `react-router` بوضع Declarative (`BrowserRouter` و`Routes` و`Route`)، وهو أبسط أوضاعها.
- الإصدار 8 يتطلب Node 22.22 أو أحدث، وجهاز التطوير عليه Node 22.14، و`engine-strict=true` يمنع تثبيته. لذلك ثبّتنا `react-router@^7`.
- الترقية إلى 8 ممكنة لاحقاً بعد تحديث Node.

**5. حماية الصفحات**

- `RequireAuth`: الصفحات الداخلية للمستخدم المسجّل فقط، وغيره يُحوَّل إلى `/login`.
- `GuestOnly`: صفحة الدخول تحوّل المستخدم المسجّل إلى الصفحة الرئيسية.
- هذه حماية لتجربة الاستخدام فقط. **الحماية الحقيقية في الخادم**: كل طلب بيانات يتحقق من الـ token والجلسة.

## النتائج

- تحديث الصفحة لا يُخرج المستخدم، ما دام الـ refresh token صالحاً (7 أيام).
- إغلاق كل التبويبات ثم فتح المنصة خلال 7 أيام يعيد الجلسة دون كلمة مرور. الخروج الصريح يلغي الجلسة في الخادم.
