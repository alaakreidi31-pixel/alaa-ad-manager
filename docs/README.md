## سجل القرارات (ADR)

كل قرار في ملف مستقل يحتوي: السياق، والقرار، والبدائل، والنتائج، ومتى نراجعه.

**حالات القرار:**

- **منفّذ:** موجود فعلاً في الكود ومُختبَر.
- **معتمد، لم يُنفَّذ بعد:** اتُّفق عليه، ويُطبَّق في مرحلة لاحقة محددة.
- **مقترح، بانتظار التأكيد:** قاعدة اقترحها المساعد أثناء العمل ولم تُعتمد صراحةً بعد.
